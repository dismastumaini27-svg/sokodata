# Contributing to SokoData

1. Keep every price linked to its original source. Never estimate a missing price.
2. Keep ministry data and newspaper data in separate files.
3. Add new text in both Kiswahili and English (the `T` block in `assets/app.js`).
4. Test locally with `python -m http.server 8000` before uploading.
5. Describe each change in one line when you commit on GitHub.
